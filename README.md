# TP2 CSS — Images et Images d'arrière-plans

## Présentation du cours

Ce TP propose deux exercices pour apprendre à afficher et à mettre en forme des images avec HTML et CSS. Le premier construit des avatars réutilisables à partir de balises `<img>`. Le second explore les images et les dégradés utilisés comme arrière-plans CSS.

Les pages sont déjà préparées : observez les exemples, puis modifiez les règles signalées dans les fichiers CSS pour en comparer les effets. L’objectif est d’expérimenter, de formuler des observations et de comprendre pourquoi le rendu change.

## Méthode de travail

1. Lisez le texte de l’étape et observez l’exemple.
2. Repérez dans `css/style.css` la règle indiquée par un commentaire ou dans la consigne.
3. Modifiez une seule propriété à la fois.
4. Enregistrez et rechargez la page pour observer le résultat.
5. Notez ce qui change, puis essayez une autre valeur.

Les styles de base sont dans `css/default.css` ; les règles de l’exercice et les zones d’expérimentation sont dans `css/style.css`. Conservez la structure HTML, sauf lorsque la consigne demande explicitement de tester des attributs ou du balisage.

## Objectifs pédagogiques

À la fin de ces exercices, vous devriez savoir :

- intégrer une image avec `<img>` et rédiger un texte alternatif pertinent ;
- adapter une image à un conteneur sans la déformer ;
- structurer un composant CSS avec la convention BEM et ses modificateurs ;
- superposer des éléments décoratifs à une image ;
- créer un arrière-plan à partir d’une image, d’un dégradé ou de plusieurs couches ;
- régler la taille, la répétition, la position et le comportement d’un arrière-plan ;
- distinguer la zone de référence d’un arrière-plan (`background-origin`) de la zone où il est peint (`background-clip`) ;
- utiliser le raccourci `background` en connaissant son effet de réinitialisation.
