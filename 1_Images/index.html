Les avatars

Observez chaque exemple, puis modifiez la règle indiquée dans css/style.css pour construire votre collection d’avatars étape par étape.

01 · L’image

Afficher une image

La balise <img> affiche une image dans la page. Son attribut alt décrit l’image aux personnes qui ne peuvent pas la voir.

Partie HTML : Testez les attributs src, alt, width et height (valeurs sans unité, interprétées en pixels par le navigateur).

Partie CSS : Modifiez la largeur de l’image dans .test-image dans css/style.css.

Remarque : Il est possible de modifier les dimensions, le comportement des images à l’aide des propriétés CSS suivantes : width - height - aspect-ratio - max-width - object-fit - object-position - border-radius
Remarque : Vous pouvez tester les différents placeholders d’images disponibles sur le web :
  • https://picsum.photos
  • https://www.pexels.com
  • https://i.pravatar.cc/{size}
  • https://doodleipsum.com

Testez les placeholders : https://picsum.photos/480/320/?random

02 · Avatar - l'image s'adapte à son conteneur

Créer un avatar

Un avatar est une image recadrée dans une forme carrée ou ronde. On adapte l’image à son conteneur sans la déformer avec les propriétés object-fit et object-position.

Rappel BEM du COMPOSANT AVATAR : 
BLOCK .avatar (une simple div)
ELEMENT
  .avatar__img (une balise img)
MODIFIERS
  .avatar--small
  .avatar--large
  ...

À tester : Dans .avatar, changez border-radius et aspect-ratio. Dans .avatar__img, comparez cover et contain. Positionnez l’image avec object-position.

Question : Comment l’image est-elle rognée en cercle alors que le parent a border-radius: 50% ? Comparez deux approches :
  • overflow: hidden sur le conteneur .avatar
  • border-radius: inherit sur l’image .avatar__img

03 · La taille

Agrandir l’avatar

Une classe modificatrice permet de changer la taille tout en gardant les règles de base de l’avatar.

À essayer : Modifiez la largeur de .avatar--large dans css/style.css.

04 · La bordure

Ajouter une bordure

Une bordure sépare visuellement l’avatar de son arrière-plan. Elle s’ajoute à la taille de base sans modifier l’image.

À essayer : Changez l’épaisseur et la couleur de la bordure dans .avatar--bordered.

05 · La forme carrée

Modifier les coins

La même classe modificatrice peut transformer un avatar rond en avatar carré.

À essayer : Testez différentes valeurs de border-radius dans .avatar--square.

06 · Le dégradé

Créer une bordure dégradée

Un arrière-plan en dégradé et une bordure transparente permettent d’obtenir un contour coloré autour de l’image.

À essayer : Modifiez les couleurs et l’angle du dégradé dans .avatar--b-gradient. Essayez ensuite la version carrée.

07 · Le contour double

Ajouter un contour intérieur

outline ajoute un contour sans occuper d’espace dans la boîte. Un décalage négatif le place à l’intérieur de l’avatar.

À essayer : Changez la couleur et l’épaisseur de outline, puis comparez plusieurs valeurs d’outline-offset.

07 bis · Le pseudo-élément ::after

Superposer un contour avec ::after

Le pseudo-élément ::after permet de créer un calque décoratif superposé à l’avatar. Grâce à position: absolute et inset: 0, il recouvre parfaitement l’image sans modifier le flux HTML.

À essayer : Observez l’utilisation indispensable de content: "" pour afficher le pseudo-élément. Modifiez les propriétés d’outline, d’outline-offset ou ajoutez une bordure dans .avatar--b-after::after.
